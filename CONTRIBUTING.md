# Contributing to Progestion

We love your input! Whether it's a bug report, a new feature, or a code improvement, we appreciate your help in making **Progestion** better.

[Français Version (Version Française)](CONTRIBUTING.fr.md)

---

## 🚀 How to Contribute

### 1. Reporting Bugs
- Search existing issues to see if the bug has already been reported.
- If not, open a new issue using the **Bug Report** template.
- Provide as much detail as possible, including steps to reproduce.

### 2. Suggesting Features
- Open a new issue using the **Feature Request** template.
- Explain why the feature would be useful and how it should work.

### 3. Submitting Code
- Fork the repository and create your branch from `main`.
- Install development dependencies.
- Follow the coding standards (PEP 8 for Python).
- Ensure your code is well-documented.
- Submit a Pull Request (PR) with a clear description of your changes.

## 🛠️ Local Development Setup

Refer to the [README.md](README.md) for basic installation instructions. 

### Coding Standards
- Use `flake8` or `black` for code formatting.
- Follow Django best practices for templates and views.
- Ensure all new features are covered by tests.

## ⚖️ Code of Conduct
By participating in this project, you agree to abide by our [Code of Conduct](CODE_OF_CONDUCT.md).

## 🛡️ Security Vulnerabilities
Please report security issues privately according to our [Security Policy](SECURITY.md).
