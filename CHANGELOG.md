## [1.0.0] - 2026-04-08

### Added
- Initial release of Progestion.
- **Core modules**: Accounts, Commercial, Customers, Invoicing, Tax, Products, Suppliers, Transactions.
- **Tech stack**: Django 5.1, Tailwind CSS, HTMX, WeasyPrint.
- **Documentation**: Fully bilingual (English/French) community documentation.
- **Templates**: Issue and Pull Request templates added for GitHub.
