# Contribuer à Progestion

Merci de votre intérêt pour le projet ! Que ce soit pour un rapport de bogue, une nouvelle fonctionnalité ou une amélioration du code, nous apprécions votre aide pour rendre **Progestion** meilleur.

[English Version (Version Anglaise)](CONTRIBUTING.md)

---

## 🚀 Comment Contribuer

### 1. Rapporter des Bogues
- Recherchez dans les issues existantes pour voir si le bogue a déjà été signalé.
- Si ce n'est pas le cas, ouvrez une nouvelle issue en utilisant le modèle de **Rapport de Bogue**.
- Fournissez autant de détails que possible, y compris les étapes pour reproduire le problème.

### 2. Suggérer des Fonctionnalités
- Ouvrez une nouvelle issue en utilisant le modèle de **Demande de Fonctionnalité**.
- Expliquez pourquoi la fonctionnalité serait utile et comment elle devrait fonctionner.

### 3. Soumettre du Code
- Forkez le dépôt et créez votre branche à partir de `main`.
- Installez les dépendances de développement.
- Suivez les standards de codage (PEP 8 pour Python).
- Assurez-vous que votre code est bien documenté.
- Soumettez une Pull Request (PR) avec une description claire de vos changements.

## 🛠️ Configuration de Développement Local

Reportez-vous au [README.fr.md](README.fr.md) pour les instructions d'installation de base.

### Standards de Codage
- Utilisez `flake8` ou `black` pour le formatage du code.
- Suivez les bonnes pratiques de Django pour les templates et les vues.
- Assurez-vous que toutes les nouvelles fonctionnalités sont couvertes par des tests.
