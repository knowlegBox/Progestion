## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not open a public issue.** This could expose users to the vulnerability before a fix is available.
2. Send an email to [INSERT EMAIL ADDRESS] with a description of the vulnerability.
3. Include details on how to reproduce the issue, and if possible, a suggested fix.

We will acknowledge your report within 48 hours and provide a timeline for a fix if necessary. Once the vulnerability is resolved, we will publish a security advisory and credit you for your discovery (unless you prefer to remain anonymous).

Thank you for helping keep **Progestion** secure!
